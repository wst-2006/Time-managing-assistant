# 界面设计说明（海报版）

这份说明记录界面重做后的设计约定，方便以后继续改页面时保持一致。

## 概念：印在红色海报上的时间表

- **底色**：信号红 `--red: #ff1446`。面板不填色，只用 1.5px 黑色描边（`--rule`）。
- **墨色**：`--ink: #160000`。凡是“正在发生 / 被选中 / 可以按下”的东西都是黑底红字的墨块。
- **米白** `--cream`：只用于必须打断红色的提醒（错误、冲突、待评价）。
- 没有圆角，没有模糊阴影，只有硬投影（`--shadow-2`、`--shadow-pop`）。
- 状态不靠色相区分，靠填充方式：实心黑 = 完成/满意，斜线 = 进行中/一般，米白 = 不满意/警告，空框 = 没有数据。

所有颜色、字体、阴影和动效时长都在 `apps/web/src/ui/tokens.css`。

## 结构：三个空间

顶栏是三个空间，下面一条细栏列出全部页面，按空间分组：

| 空间 | 页面 |
| --- | --- |
| 此刻 NOW | 今日、专注 |
| 时间 TIME | 规划、健康 |
| 回声 ECHO | 复盘、日记、成长 |

设置、数据备份和“与 AI 一起整理”（Ctrl K）在顶栏右侧。

## 字体（全部随应用打包，桌面版离线可用）

- 巨大的中文标题：ZCOOL QingKe HuangYou（站酷庆科黄油体）
- 大数字、倒计时：Anton
- 小标签、时间刻度：IBM Plex Mono
- 标语与正文段落：Instrument Serif / Noto Serif SC
- 表单与密集列表：系统无衬线（微软雅黑 UI / 苹方）

## 组件（`apps/web/src/ui/poster.tsx`）

- `PosterHeader` / `PosterMark`：每页顶部的巨字 + 跟随鼠标弯曲的波纹线。
- `Tunnel`：透视隧道。今日页的“此刻”区和专注页（默认主题）都用它。
- `Sun`：今日页的太阳，高度 = 07:00–23:00 已经过去的比例，太阳本身就是“开始专注”按钮。
- `Scramble`：等宽标签出现和悬停时会乱码重排。
- `Rolling`：数字逐位滚动。
- `Cursor`：跟随鼠标的圆环，悬停可点元素时放大，可拖动的时间块上显示“拖动”。

## 动效

- 切页：一块黑幕从下往上盖住页面，中间写着下一页的名字，再向上揭开（约 0.9 秒）；往回走时方向相反。
- 时间块悬停会抬起并投下硬阴影，按住拖动时会歪一下。
- 弹窗和 AI 侧边层用“擦出”的方式进入。
- 画布动画在窗口隐藏或滚出视野时暂停。
- 系统开启“减少动态效果”时，切页黑幕和画布动画全部关闭。
