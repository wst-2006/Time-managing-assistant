# Personal AI Assistant v0.1.44

本版本汇总了 `v0.1.27` 之后的正式功能更新，并修复专注主题在休息阶段的显示问题。

## 本次更新

- 完善桌面端与飞书之间的任务创建、排期调整、提醒卡片和状态同步。
- 改进专注准备、迟到开始、计时、休息和待评价流程的状态恢复。
- 为五套专注主题补充更完整的计时与评价视觉表现。
- 修复“素简翻页”主题休息阶段深色文字叠在深色翻页面板上、难以辨认的问题；休息阶段现在使用白色背景和黑色文字，同时保留翻页动效与原有窗口尺寸。
- 移除当前产品未使用的外部新闻、联网搜索和独立每日简报链路，保留本地复盘与日记流程。

## 安装要求

- Windows 10/11 x64
- PostgreSQL 18.x（本地安装并运行）
- 可选：AI、视觉模型和飞书应用凭据

## 下载

- `Personal AI Assistant_0.1.44_x64-setup.exe`
- `SHA256SUMS.txt`

这是未进行商业代码签名的 Windows x64 NSIS 安装程序，首次安装时 Windows SmartScreen 可能显示信誉提醒。安装包不包含本地 `.env`、API Key、数据库、日志或个人记录。
